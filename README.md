## asset directory

| file name | format | background | description |
| :--- | :---: | :---: | :--- |
| [`logo.jpg`](logo.jpg) | jpg | dotted grid | Original source artwork with dot-grid canvas. |
| [`logo_precise_transparent.png`](logo_precise_transparent.png) | png | transparent | High-precision transparent background cutout. |
| [`logo_precise_white.png`](logo_precise_white.png) | png | solid white | High-precision cutout on solid white canvas. |
| [`logo_transparent.png`](logo_transparent.png) | png | transparent | Standard transparent PNG variant. |
| [`logo_white_background.png`](logo_white_background.png) | png | solid white | Clean solid-white background PNG. |
| [`logo_white_background.jpg`](logo_white_background.jpg) | jpg | solid white | Clean solid-white background JPG. |
| [`logo_rembg.png`](logo_rembg.png) | png | transparent | Automated background removal variant (`rembg`). |
| [`logo_rembg_white.jpg`](logo_rembg_white.jpg) | jpg | solid white | Automated background removal on solid white JPG. |

## recommended usage

- **web & interfaces:** Use [`logo_precise_transparent.png`](logo_precise_transparent.png) for seamless integration across light and dark modes.
- **documents & print:** Use [`logo_white_background.png`](logo_white_background.png) or [`logo_white_background.jpg`](logo_white_background.jpg).
- **original context:** Reference [`logo.jpg`](logo.jpg) for the unedited design asset.
